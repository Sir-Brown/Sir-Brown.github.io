# D'Jaine Brown — Portfolio

A personal portfolio for documenting my development as a Computer Science student, aspiring software developer, and creative practitioner.

## Site structure

- **Home** — introduction and overview
- **About** — background and interests
- **Projects** — completed, in-progress, and planned work with clear status labels
- **Skills & Development** — technical foundations and current learning goals
- **Creative** — photography, cinematography, and music
- **Resume & Contact** — professional information and contact links

## Built with

- HTML
- CSS
- Vanilla JavaScript
- Git and GitHub Pages

## Design and behavior

The visual system uses an oxblood and charcoal palette. Dark theme is the default unless the visitor's operating system requests light mode; visitors can switch themes manually, and their choice is saved locally. The navigation adapts for smaller screens and respects reduced-motion preferences.

## Status

This portfolio is actively being developed. Project statuses on the site distinguish work in progress from ideas that are only planned.
